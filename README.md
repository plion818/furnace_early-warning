# 加熱爐數據趨勢分析與異常偵測系統 (Heating Furnace Anomaly Detection)

這是一個用於分析加熱爐感測器數據並偵測異常（特別是阻抗異常）的系統。它包含一個用於執行偵測邏輯的 FastAPI 後端，以及一個用於數據視覺化和互動的 Streamlit 前端。

## 專案結構

- **main.py**: FastAPI 後端應用程式入口，提供異常偵測 API。
- **homepage.py**: Streamlit 前端應用程式入口，提供數據儀表板與操作介面。
- **anomaly_detection.py**: 包含核心的異常偵測演算法（滑動視窗法）。
- **requirements.txt**: 專案依賴套件列表。
- **data/**: 存放數據檔案的目錄。
- **.env**: 環境變數設定檔。

## 安裝說明

1. **環境準備**
   確保您已安裝 Python 3.8 或更高版本。

2. **安裝依賴套件**
   在專案根目錄下執行以下指令以安裝所需的 Python 套件：
   ```bash
   pip install -r requirements.txt
   ```

## 設定說明

專案使用 `.env` 檔案來管理環境變數。請確保根目錄下有 `.env` 檔案，並包含以下設定（已預設）：

```env
API_URL=http://127.0.0.1:8000/detect_anomaly/
API_TOKEN=your_api_token_here
```

- `API_URL`: 後端 API 的位址。
- `API_TOKEN`: 若 API 需要驗證，請在此填入 Token（目前範例為預留）。

## 使用說明

本系統分為後端與前端兩個部分，需分別啟動。

### 1. 啟動後端 (FastAPI)

開啟一個終端機 (Terminal)，執行以下指令：

```bash
uvicorn main:app --reload
```

啟動後，API 伺服器將在 `http://127.0.0.1:8000` 運行。您可以透過瀏覽器訪問 `http://127.0.0.1:8000/docs` 查看 API 文件。

### 2. 啟動前端 (Streamlit)

開啟另一個新的終端機，執行以下指令：

```bash
streamlit run homepage.py
```

啟動後，系統會自動在瀏覽器中開啟前端頁面（預設為 `http://localhost:8501`）。

### 3. 系統操作

1. **數據瀏覽**：前端頁面會自動載入 `data/processed/` 下的感測器數據，您可以透過側邊欄選擇時間區間與要觀察的指標（電流、電壓、阻抗、溫度）。
2. **異常偵測**：
   - 在側邊欄點擊 **「🔥 偵測阻抗異常點 (透過 API)」** 按鈕。
   - 系統會將當前數據發送至後端 API 進行分析。
   - 分析完成後，異常點將會在圖表上以紅點標示，並提供異常統計資訊。
3. **匯出資料**：偵測完成後，您可以下載包含異常標記的 CSV 檔案。

## 功能特色

- **滑動視窗異常偵測**：利用 Z-score 與滑動視窗技術，動態識別數據中的異常波動。
- **互動式圖表**：使用 Plotly 繪製，支援縮放、懸停查看詳細數值。
- **前後端分離架構**：清晰的架構設計，便於維護與擴充。
